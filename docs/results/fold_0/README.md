# Fold 0 Result Artifacts

These files are small release copies of the completed fold0 evaluation outputs.

- `metrics.json`: score metrics copied from `outputs/evaluation/fold_0/metrics.json`.
- `confusion_matrix.json`: pairwise confusion matrix copied from `outputs/evaluation/fold_0/confusion_matrix.json`.
- `progress.json`: final completed progress payload copied from `outputs/evaluation/fold_0/progress.json`.

The full generated predictions CSV is not duplicated here because `outputs/evaluation/fold_0/pairwise_predictions.csv` is about 45 MB and is a generated artifact.
